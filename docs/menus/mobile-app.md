# 모바일 앱 시스템 지침

## 목적과 경로

- `/mobile`은 기존 주간자료 시스템과 같은 Supabase 데이터와 서버 액션을 사용하는 모바일 전용 화면이다.
- 별도 데이터베이스나 별도 로그인 체계를 만들지 않는다. 보호 레이아웃의 인증·활성 사용자 검사를 그대로 통과해야 한다.
- `/mobile`은 인증 미들웨어의 보호 경로이며, 비로그인 진입 시 쿼리를 포함한 원래 모바일 주소를 `redirectTo`로 보존한다. 로그인 완료 또는 로그인 상태에서 로그인 URL에 접근하면 `/notices`가 아니라 보존된 모바일 주소로 복귀한다.
- 모바일 로그인 화면은 상단 물류 이미지에 `TPL사업부 주간자료 시스템`만 표시하고 바로 아래 로그인 폼을 배치한다. 영문 홍보 문구와 부서 연결·물동량·승인 흐름·회의자료 지표는 모바일에서 표시하지 않는다.
- 모바일 설정에서 로그아웃하면 `/login?redirectTo=/mobile&mode=mobile`로 이동하며, 브라우저 폭과 관계없이 모바일 로그인 레이아웃을 표시한다.
- 웹 앱 매니페스트의 시작 경로는 `/mobile`이며 홈 화면 설치 시 세로형 독립 앱으로 실행된다.

## 화면 구조

- 데스크톱 사이드바와 헤더 대신 모바일 전용 상단 상태 영역과 화면 하단의 `화주자료`, `부서자료`, `미니게임`, `설정` 메뉴를 사용한다. 미니게임은 부서자료 오른쪽에 배치한다.
- 최상단 파란색 헤더는 좌측에 시스템 명칭, 우측에 권한 범위의 부서·화주 필터를 표시하며 실제 조회 범위를 변경한다.
- 모바일 헤더는 한 줄 높이로 유지하며 부서·화주 필터는 102px 폭과 12px 글꼴을 사용한다. 필터 글꼴은 년도·월 필터와 같은 서체와 굵기를 사용한다. 별도의 메뉴명·소속·사용자 정보 행은 표시하지 않는다.
- 하단 메뉴 전환은 이미 열린 화면의 로컬 상태를 교체하고 URL의 `view` 값을 갱신한다. 브라우저 뒤로가기도 같은 상태를 복원한다.
- 주차·화주 변경처럼 데이터 범위가 달라질 때만 서버 페이지를 다시 조회한다.
- 화주자료의 부서 선택은 관리자에게 활성 부서 전체를 제공하고, 비관리자에게는 소속부서만 제공한다. 부서 변경 시 해당 부서의 화주 범위를 다시 계산한다.

## 화주자료

- 현재 데스크톱 화주자료와 동일한 보고서·항목·물동량 저장 액션을 사용한다.
- 금주 실시사항, 차주 예정사항, 물동량을 모바일 입력 화면에서 작성하고 초안 저장, 확정, 허용 기간 내 확정취소를 수행한다.
- 상단의 금주 실시사항, 차주 예정사항, 물동량 버튼은 기존 팝업 작성 방식을 유지한다.
- 금주 실시사항, 차주 예정사항, 물동량의 작성 아이콘은 각 내용 영역 제목의 가장 오른쪽에 배치한다.
- 년도·월·주차 필터는 모바일 폭에 맞게 압축하고 라벨과 선택값은 작성 항목 제목과 같은 14px로 표시한다. 오른쪽에서 보고서 확정, 확정취소 또는 승인 상태를 처리한다.
- 화주자료 하단에는 별도의 확정 자료 이력 카드를 표시하지 않는다. 선택한 주차의 자료가 확정 또는 승인 상태이면 기존 작성 영역에서 내용을 조회한다.
- 화주자료 작성 영역은 선택 화주명을 좌측 상단에 표시하는 단일 카드로 구성하고, 금주 실시사항·차주 예정사항·물동량을 카드 내부 구분선으로 나눈다. 작성 완료 후 저장된 내용은 각 구역에 즉시 반영한다.
- 버튼 아래에는 저장된 내용을 금주 실시사항, 차주 예정사항, 물동량 순서로 항상 펼쳐 표시한다.
- 금주·차주 항목의 업무구분 배지는 웹 화면과 동일하게 중요도별 빨강·주황·초록·회색으로 표시하며 부서자료의 확정 화주자료에도 같은 규칙을 적용한다.
- 최근 12건을 조회하며 `submitted`, `approved` 상태의 확정 자료를 읽기 전용으로 펼쳐 볼 수 있다.
- `client_owner`는 활성 `client_assignments`로 배정된 화주만 표시하고 작성할 수 있다.

## 부서자료

- 모바일에서는 `공통사항`, `물동량`, `공휴일근무`, `시설공사`를 탭으로 제공한다.
- 공통사항 아래 `확정된 화주자료`에는 선택 부서에 소속된 전체 화주를 표시하고, 선택 주차의 보고서 상태에 따라 `확정` 또는 `미확정`으로 구분한다. 제목 우측에는 `확정 수/전체 화주 수`를 표시한다.
- `부서 공통사항` 제목 행은 모바일에서 접고 펼칠 수 있으며, 접은 상태에서도 아래 화주자료 확정 현황은 계속 표시한다.
- 모바일 부서 공통사항은 제목 아래에 별도 작성 버튼을 두지 않는다. 금주 실시사항과 차주 예정사항 카드 제목 우측의 `작성` 버튼에서 해당 입력 팝업을 연다.
- 확정 화주자료는 기본 접힘 상태이며 화주명 행을 선택해 세부 내용을 열고 닫는다. 미확정 화주는 상태만 표시한다.
- 부서자료의 년도·월·주차 필터는 모바일 폭에 맞게 압축하고 라벨과 선택값을 화주자료와 동일한 14px로 표시한다. 오른쪽에 확정, 확정취소 또는 승인 상태를 표시한다.
- 네 개 부서자료 탭은 아이콘과 13px 제목을 세로 정렬해 좁은 화면에서 줄바꿈과 높이 변화를 방지한다.
- 물동량 탭은 선택 부서·주차의 모든 활성 화주를 행으로 표시하고 상단에 입고·출고·합계 수량을 단위별로 집계한다. 표 컬럼은 화주, 입고, 출고, 합계이며 합계는 저장된 별도 행이 아니라 입고와 출고의 합이다.
- 시설공사 목록은 시작일, 공사내용, 진행업체만 요약 표시하고 상세 버튼의 팝업에서 나머지 정보와 수정 진입을 제공한다.
- 공휴일근무 목록은 일자, 화주, 근무자, 도급인원만 요약 표시하고 상세 버튼의 팝업에서 근무사유, 청구여부, 비고와 수정 진입을 제공한다.
- 기존 `DepartmentSubmissionEditor`와 부서자료 저장·확정 액션을 재사용한다. 물동량은 화주자료 원본을 읽는 조회 전용이며 공실은 모바일 범위에서 제외한다.
- 관리자, 부서장, 매니저만 작성할 수 있다. 매니저는 초안 저장까지만 가능하고 사업부 확정은 관리자와 부서장에게만 허용한다.
- 화주담당자에게 부서자료 쓰기 권한을 새로 부여하지 않는다. 해당 역할에서는 권한 안내를 표시한다.

## 설정

- 로그인 사용자 이름, 역할, 활성 계정 여부, 소속부서, 이메일, 사번을 표시한다.
- 관리 가능한 화주 목록은 현재 역할과 활성 배정 범위를 반영한다.
- 로그아웃은 기존 `signOutAction`을 사용한다.

## 미니게임

- `view=game`은 흰 망토를 두른 하얀 강아지가 교외 마을 상공을 비행하는 모바일 Canvas Endless Shooter다.
- 흰둥이는 화면 아래에서 위를 향해 비행하고 적은 화면 위에서 아래로 내려온다. 게임 화면 좌측 하단 조이스틱으로 자유 이동하며 우측 하단 필살기 버튼을 사용한다.
- 자동발사, 5칸 기본 체력, 1초 피격 무적, 회복 아이템, 필살기, 콤보, 적 4종, 90초 미니보스와 5분 메인보스를 제공한다.
- 적 처치 경험치로 레벨업하며 3개 무작위 능력 중 하나를 선택한다. 최고점수, 사운드 설정, 업적은 LocalStorage에 저장한다.
- 다중 탄환은 5레벨 단위에서만 선택지로 등장하고 최대 3발까지 확장된다. 게임오버 화면은 로그인 사용자의 현재 순위와 전체 TOP 10을 함께 표시한다.
- 기본 체력은 5칸이며, 레벨업 능력 선택 직후 1초 동안 피격 무적을 적용한다. 조이스틱 손잡이는 React 렌더링을 거치지 않고 포인터 입력과 동시에 엔진과 화면에 반영하며, 작은 입력도 즉시 움직임이 느껴지도록 비선형 입력 곡선을 사용한다. 조이스틱에서 시작한 터치는 조작 범위를 벗어나도 전역 포인터 추적으로 방향 입력을 유지한다.
- 지원 기기에서는 고빈도 원시 포인터 입력을 함께 사용한다. 난이도 상승 속도는 최초 기준의 35%로 적용하고 적 생성 간격, 이동속도, 공격 간격과 탄환 속도도 함께 완화해 직전 설정 대비 약 절반 수준의 전투 압력을 유지한다. 보스 출현 주기는 유지한다.
- 초반 난이도는 유지하되 플레이 90초 이후부터 시간 기반 난이도 상승 기울기를 추가해 적 생성과 공격 압력이 후반으로 갈수록 연속적으로 증가한다. 90초 경계에서 난이도가 즉시 뛰는 변화는 만들지 않는다.
- 일반 적 구간은 직전 설정보다 소폭 강화한다. 스킬 강화는 종류별 최대 Lv.3까지만 가능하며 최대 레벨 스킬은 이후 선택지에서 제외한다.
- 미니보스는 원형 탄막 없이 한 번에 탄환 1발만 발사한다. 메인보스는 기존 미니보스 수준의 체력과 3발 공격을 사용하고 적 소환을 하지 않는다. 모든 보스 탄환은 직전보다 30% 느리다.
- 솜사탕 배경과 흰둥이 이미지 에셋은 미리 불러오되 일부 또는 전체 로드에 실패하면 기존 Canvas 벡터 그래픽으로 대체한다. Canvas 내부 좌표는 390×620을 유지하고 기기 픽셀 배율은 최대 2배까지만 적용한다. 동작 줄이기 설정에서는 화면 흔들림, 파티클, 배경 움직임을 생략한다.
- 플레이 중에는 고정 하단 메뉴를 숨겨 조이스틱과 게임 화면을 가리지 않으며, 시작 화면과 게임오버 화면에서는 메뉴를 다시 표시한다.
- 게임 종료 점수는 기존 `saveMiniGameScoreAction` 계약으로 현재 로그인 사용자에게 1회 저장한다. 업무 보고서나 승인 데이터와 결합하지 않는다.
- 엔진, 렌더러, 오브젝트 풀, 사운드, 저장소, UI를 `src/components/game/sky-pup` 아래 기능별 파일로 분리한다.

## 변경 원칙과 검증

- 모바일 전용 스타일을 위해 기존 보고서 저장 형식, 상태 전이, RPC, RLS를 복제하거나 우회하지 않는다.
- 모바일 헤더는 한 줄 높이로 유지하며 부서·화주 필터는 102px 폭과 12px 글꼴을 사용한다. 별도의 메뉴명·소속·사용자 정보 행은 표시하지 않는다.
- 공유 편집기나 액션을 변경할 때는 `client-reports.md`, `department-reports.md`도 함께 확인한다.
- 390px 전후 모바일 뷰포트에서 하단 메뉴, 네 개 부서 탭, 물동량 표, 주차 선택, 작성 팝업의 겹침과 가로 스크롤을 확인한다.
- 관리자와 화주담당자 계정에서 메뉴 노출, 화주 범위, 부서자료 작성 제한을 각각 검증한다.
