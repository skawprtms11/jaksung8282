# 권한 매트릭스

| 기능 | 관리자 | 부서장 | 매니저 | 화주담당자 |
| --- | --- | --- | --- | --- |
| 전체 부서 조회 | 가능 | 불가 | 불가 | 불가 |
| 소속 부서 조회 | 가능 | 가능 | 가능 | 가능 |
| 마스터 등록·수정 | 가능 | 불가 | 불가 | 불가 |
| 화주별 자료 작성 | 전체 | 소속 부서 | 소속 부서 | 배정 화주 |
| 화주별 자료 승인·반려 | 전체 | 소속 부서 | 소속 부서 | 불가 |
| 부서 공통자료 작성 | 전체 | 소속 부서 | 소속 부서 | 읽기 |
| 사업부 검토요청 | 가능 | 가능 | 불가 | 불가 |
| 사업부 최종 승인·반려 | 가능 | 불가 | 불가 | 불가 |
| 공지 등록·수정·삭제 | 가능 | 불가 | 불가 | 불가 |

서버 액션과 RLS 모두 동일 원칙을 적용한다. 클라이언트에서 부서 ID나 화주 ID를 변조해도 RLS helper 함수가 실제 소속과 담당자 배정을 다시 확인한다.
